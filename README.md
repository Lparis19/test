# Portfolio de Lucas

Portfolio estático listo para GitHub Pages. No necesita servidor, Node.js ni variables de entorno.

Los proyectos se leen desde `data/projects.json`. Para añadir o editar uno, modifica ese archivo y sube los cambios al repositorio.

## Publicar en GitHub Pages

1. Sube el contenido de esta carpeta a un repositorio de GitHub.
2. En **Settings → Pages**, elige **Deploy from a branch**.
3. Selecciona la rama `main` y la carpeta `/(root)`.
4. Guarda. GitHub publicará el sitio en la URL indicada.
